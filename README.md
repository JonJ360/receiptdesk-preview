# ReceiptDesk — non-commercial prototype preview

Internal evaluation/demo of a receipt workflow owned by Apollo LLC. This is not the production subscription service, a storefront, or an active commercial SaaS deployment. No sales, payments, customer-account provisioning or accounting-system posting are available here.

The root preview opens a preconfigured 360 Solutions sample workspace without login. It contains GL account numbers/names authorized by Jon for demonstration; all preloaded receipt images and transaction amounts are conspicuously fictional. No real balances, transaction history or personal receipts are bundled.

Root-demo uploads and edits remain in the visitor's own browser storage. Download a full backup before clearing browser data.

The separate `/pilot/` route is a private, non-commercial owner evaluation of real cloud authentication and receipt storage in the existing 360 Supabase project. Its static files are public, but database and receipt files require the authorized owner's account and backend access policies. No private receipt images or credentials are published in this repository. It does not offer signup, payments, customer provisioning or a production subscription service. The future paid service requires a commercially appropriate host and dedicated customer backends.
