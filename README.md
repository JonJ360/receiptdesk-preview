# ReceiptDesk — non-commercial prototype preview

Internal evaluation/demo of a receipt workflow owned by Apollo LLC. This is not the production subscription service, a storefront, or an active commercial SaaS deployment. No sales, payments, customer-account provisioning or accounting-system posting are available here.

The preview opens a preconfigured 360 Solutions sample workspace without login. It contains GL account numbers/names authorized by Jon for demonstration; all preloaded receipt images and transaction amounts are conspicuously fictional. No real balances, transaction history or personal receipts are bundled.

Uploads and edits remain in the visitor's own browser storage. This is not shared/cloud receipt storage. Download a full backup before clearing browser data. The future paid service requires a separate commercially appropriate host and dedicated Supabase project per customer.
